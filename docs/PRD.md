# DeskGrid — 产品需求文档（PRD v1.0）

> **定位**：面向 Windows 11（兼顾 Win10）的开源桌面整理助手与增强型 Dock 栏。
> **核心理念**：Win11 Fluent 原生质感 · 零侵入可逆 · 低内存常驻 · 开箱即用。

---

## 1. 产品目标与核心原则

| 维度 | 目标与约束 |
| :--- | :--- |
| **目标平台** | Windows 11 22H2+（主力体验，完整 DWM Acrylic/Mica），兼容 Windows 10 21H2+（优雅降级半透明模糊） |
| **技术栈** | C# / .NET 10 (LTS) + WPF（内置原生 Fluent Theme）+ 原生 Win32 / DWM / Shell COM |
| **视觉语言** | Win11 Fluent Design（亚克力/云母毛玻璃、克制圆角、柔和阴影、跟随系统深浅色） |
| **分发形态** | 开源公开项目，支持安装包与绿色便携模式，支持开机自启、JSON 配置一键导入/导出 |
| **性能指标** | 常驻内存目标 **< 80 MB**（含 5 个盒子 + Dock），静置 CPU **< 0.5%**，冷启动 **< 1.5s** |
| **安全红线** | 绝不破坏用户原始文件；软件退出或异常崩溃后必须自动还原被隐藏的系统任务栏状态 |

---

## 2. 核心功能规格（MVP v1.0）

### 2.1 桌面分区盒子（Desktop Boxes）

桌面由多个可自由排布、吸附对齐的独立毛玻璃盒子构成，支持**混合管理模式**：

| 特性 | 虚拟盒子（Virtual Box） | 目录映射盒子（Folder Portal Box） |
| :--- | :--- | :--- |
| **底层数据源** | 仅保存路径/快捷方式引用清单，**不挪动原文件** | 直接绑定一个真实本地文件夹（如 `Desktop`、`Downloads`、项目目录） |
| **拖入文件/应用** | 添加引用条目（支持文件、文件夹、`.lnk`、URL） | 执行真实文件移动/复制（同盘移动、跨盘复制） |
| **拖出到外部** | 向资源管理器/其他盒子/Dock 拖出引用 | 真实文件拖出（与资源管理器一致） |
| **删除条目** | 仅从盒子移除引用，**绝不删磁盘原文件** | 移入 Windows 回收站（带二次确认，绝不默认永久删除） |
| **文件变动同步** | 检测失效路径并支持一键清理 | `FileSystemWatcher` 实时防抖同步增删改 |

#### 核心交互
1. **基础文件操作**：双击打开、拖入/拖出、`F2` 内联重命名、`Del` 移除或送入回收站、打开所在目录、固定到 Dock。
2. **卷起 / 折叠模式**：点击折叠或双击标题栏收起为标题栏；折叠态鼠标悬停自动平滑展开，移出自动卷起。
3. **外观与锁定**：自定义标题、图标尺寸（小/中/大）、透明度、排序方式、锁定位置尺寸防误拖、网格吸附对齐。
4. **桌面层级与手势**：贴合桌面层并免疫 `Win+D`；双击桌面空白处一键显隐所有盒子。

### 2.2 增强型 Dock 栏

#### 区域布局结构
```
[ 快捷工具区 ]  |  [ 固定应用 / 文件夹区 ]  |  [ 当前运行中窗口区 ]
```

1. **内置快捷工具区（最左侧）**：显隐原生桌面图标开关、显隐全部盒子开关、新建盒子按钮、偏好设置入口。
2. **固定项与运行中应用管理（中 / 右侧）**：统一合并展示固定项与活跃窗口（运行指示点/多窗口药丸），未固定运行应用展示在右侧；单应用多窗口点击弹出轻量 Fluent 窗口标题列表；支持盒子 ↔ Dock 双向拖拽。
3. **悬停图标放大动效**：60fps 波浪缩放，顶部预留透明缓冲区防裁切，支持开关与缩放倍率调节。
4. **任务栏协同与全屏避让**：未隐藏原生任务栏时悬浮于工作区底部上方；可选隐藏原生任务栏并在退出/异常时安全恢复；全屏游戏/视频自动静默隐藏 Dock。

---

### 2.3 首次启动预设、系统托盘与配置管理

- **首次启动开箱预设**：无本地配置时自动创建“桌面文件”（绑定 `Desktop`）+“常用快捷”（虚拟盒子）+ 底部 Dock，不主动隐藏用户原生桌面图标。
- **系统托盘**：原生 Win32 托盘图标 + Fluent WPF 菜单。
- **配置管理**：JSON 原子写入 + 滚动备份 + 一键导出/导入配置 + 无 UAC 开机自启。
